## 关键根因（下批直接照做）
- **A4**：148 起走 HTTP poll 模式，`startHeartbeat` 只挂 `wsClientDidConnect`(L480)、poll 模式从不连 WS → heartbeat 从不启动 → 账号从不 POST。修复走 poll 同款通道 `XNURLProtocol sendMessage`（L188 带 secret），不受 isConnected/heartbeat 门控。
- **open_tab profile 类名匹配恒失败**：`TTKProfileHomeViewController` 与 tab bar 实际 VC 类名不符 → class_no_match → acc_id_tap 触摸（43.7.0 触摸墙拒）→ 旧代码无条件假 success。149 改诚实 failed + realTabVCs 取证。**装机后看 server.log realTabVCs 拿真实类名 → 下版用它做 setSelectedIndex 直切 profile（解锁账号管理页/切号/改资料）**。

## 决策副作用
- open_tab profile/inbox/friends 触摸兜底从「假 success」变「诚实 failed」——后台任务会被标 failed（有真实 error 消息），不再误导。代价：走触摸路径的真实切页（未来若触摸解锁）会被误报 failed，需同步补落位验证才可解除。
