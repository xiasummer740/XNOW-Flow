## 🔴 验证中新抓 bug → v1.4.123 已修

**现象**：祥哥给测试值 outshine1 验修改资料，下发 `edit_profile {nickname:"outshine1"}` → 命令级 success（duration 5）但控件树昵称仍 `Outshine/@outshine83`，**没改成功**。

**根因**（ui_scan 控件树 + 代码逐行）：
- 编辑资料按钮真实 accId = `user_info_manage_edit_profile`（**下划线**）
- `_performEditProfile` 找按钮用 `_findButtonWithAnyLabel:@[@"Edit profile", ...]`，其内部 `accId.lowercaseString containsString:lowerLabel` → `"edit profile"`（带空格）vs `user_info_manage_edit_profile`（下划线）**不命中**
- 找不到 → 坐标兜底 `(width-40, height*0.38)`=(374,340)，而编辑按钮实际中心约 (288,177) → **点偏 → 编辑资料页根本没打开**
- v1.4.119 只修了输入框赋值（`_setEditableFieldText`），**漏了编辑按钮定位** → 赋值永远没机会执行

**修复**（CommandEngine.m，已编译 xnower-123 760392B，已打包上传 TikTok_XNOW_v1.4.123_BH.ipa md5 7890335fa683284050071f3d2a4a76ed）：
1. 新增常量 `kAccEditProfile = @"user_info_manage_edit_profile"`
2. `_performEditProfile` 优先 `_findVisibleViewWithAccId:kAccEditProfile`（同 `_performFollow` 模式）
3. label 兜底（"Edit profile"/"编辑资料"），坐标兜底仅最后手段

**待装机验证**：后台改昵称 outshine1 → 编辑页打开、昵称框填入、保存生效。
