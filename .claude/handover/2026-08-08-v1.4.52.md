## 🔑 关键技术经验（血泪坑）

1. **`[self _menuTable reloadData]` 编译错**：`_menuTable` 是**成员变量**非方法，应写 `[_menuTable reloadData]`。低级错误，编译器报"expected ':'"。
2. **嵌套三元 + 嵌套 stringWithFormat 编译解析问题**：`minutes>0 ? [NSString stringWithFormat:@"%d",m] : @"x"` 会解析错，改 if/else。
3. **tiktokv.com 全量拦截 → 不稳定闪退**（v1.4.39/40）：已撤。只保留 tiktok.com/byteoversea.com 的 feed/recommend，/user/ 窄拦 tiktokv.com。
4. **固定坐标点击 = 崩溃雷区**：浮窗展开时盖住 tab/按钮位置，点击落浮窗层→崩。点赞/头像/关注/评论固定坐标兜底全部加"feed 页面判断"（`_findLargeFeedScrollViewInView`）。
5. **崩溃是信号（EXC_BAD_ACCESS）**：@try 拦不住。必须用 step 遥测定位"崩在哪一步"。
6. **上传必须临时名+改名**：上传到 `.vXXX.uploading`，完成后 mv 正式名。否则用户半路下残缺文件。
7. **爱思"验证失败"多为下载不完整**：核对文件大小（MD5 与本地一致）。
8. **崩溃前最后指令日志**：`_executeAction` 写 `XN_LastAction` 到 NSUserDefaults，SIGKILL 也留痕，下次启动上报。

## 🛠 开发工作流

1. 改代码 → `git add ios-plugin/ && git commit && git push`（触发 Actions 编译 dylib）
2. `gh run watch <run_id> --interval 5` → `gh run list --json conclusion` 确认 success（**注意 gh run watch --exit-status 会误报 0**，要查 conclusion）
3. `gh run download <run_id> --name xnower-dylib --dir gh-dl-artifacts`
4. `python3 build-bh-ipa.py gh-dl-artifacts/xnower.dylib 1.4.5X`（自检5项）
5. pscp 上传到 `/opt/xnow-flow/static/.vXXX.uploading`（后台，~15分钟/374MB）
6. 完成后 `md5sum` 对比本地 → `mv` 改名 → 通知祥哥核对大小下载
7. 设备测试：`POST /api/biz/v2/devices/{id}/command/`（admin token），看 state_diag/touch_diag/step/result
8. 后端改 ws.py 需 pscp 到 `/opt/xnow-flow/routers/ws.py` + `systemctl restart xnow-backend`（非 git 部署）
