# v1.4.125 edit_profile 崩溃根因修复 + 云控功能清单（2026-08-26 深夜）

## 做了什么
1. **定位 v1.4.125 edit_profile 装机仍崩的真正根因**（坐标修复不够）：
   - 现象：两次真机下发 edit_profile 都只有 `edit_profile:start` STEP，无后续步骤，设备离线；隔离测试 `open_tab profile` 单独导航稳定（page=profile）。
   - 实锤根因：**dispatch_sync 主线程嵌套自锁**。`_performEditProfile` 外层 `dispatch_sync(main){ _navigateToProfile }`，而 `_navigateToProfile`→`_tapTab:` 内部第一行也是 `dispatch_sync(main)` → 主线程上再 dispatch_sync(main) = 自锁 → iOS watchdog 杀进程。与 v1.4.119 智能浏览闪退同款根因。
2. **修复 3 处同类缺陷**（CommandEngine.m）：
   - `_performEditProfile:` 去掉外层 dispatch_sync 包装 → 直接调 `_navigateToProfile`
   - `_performLogout:` 同上
   - `_performRegisterAccount:` 同上
   - 原理：命令在后台线程（execQueue）执行，`_tapTab` 内部自带切主线程 = open_tab 已验证稳定模式。
3. **重新构建 + 打包 + 上传** `TikTok_XNOW_v1.4.125_BH.ipa` → `/opt/xnow-flow/static/`
4. **云控讲解.pptx 全功能识别**（5 个并行 agent）：已收齐 1-20 / 41-60 / 81-98，待 21-40 / 61-80。汇总到 `docs/云控功能清单.md`（手机端/网页端分区）。
