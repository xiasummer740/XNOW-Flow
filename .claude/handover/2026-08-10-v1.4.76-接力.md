## 🔑 关键技术经验（血泪）

1. **iOS 注入的触摸对手势按钮无效**（tab/点赞部分按钮）：合成触摸 iOS17 不触发 UITapGestureRecognizer。解法：`_setState:Recognized`（NSInvocation 私有 setter）触发手势（切tab用）；或 accId+sendActions（UIControl 用）
2. **`_setState:` 注入对某些按钮会崩**（点赞按钮是 UIControl，注入触发内部崩）：只用于纯手势 tab
3. **feed 有多个同名控件**（当前视频 + 屏外预加载 cell，y 差 ±736/±1104）：必须屏幕内过滤
4. **查找深度**：完整视图层级 11-27 层（可交互树才 8 层），深度统一 30
5. **设备重装 identifierForVendor 变 → 卡密失效**：爱思删除 App 会清 Keychain，Keychain 持久 UUID 不可靠；尝试 IOPlatformUUID（iOS17 可能沙盒限制）
6. **activate 传 device_id 和授权检查 device_id 必须一致**（self.deviceId=iphone_xxx vs deviceUID），否则"设备密钥无效"
7. **VPS 部署后必须 pkill -f uvicorn 重启**（无 lsof）
8. **上传 IPA 磁盘满会失败**（之前 100% 满）：清旧 IPA，留 2 个最新

## 🛠 开发工作流

1. 改代码 → git add 相关 + commit + push（触发 Actions 编译 dylib）
2. `gh run watch <run> --interval 5` → 查 conclusion=success
3. `gh run download <run> --name xnower-dylib --dir /tmp/xxx`
4. `python build-bh-ipa.py /tmp/xxx/xnower.dylib 1.4.XY`
5. pscp 上传 `/opt/xnow-flow/static/.v1.4.XY_BH.ipa.uploading` → md5 校验 → mv
6. 设备测试：`POST /api/biz/v2/devices/{id}/command/`（admin token），看 touch_diag/state_diag/step
7. 诊断命令：ui_scan（控件树）/ touch_diag（点击命中）/ state_diag（状态验证）/ scroll_diag
