# 2026-08-17 v1.4.105：升级提示根治 + 商业化收口验证

## 一句话
TikTok 每次启动弹 "App last updated / Update" 升级提示的**根因 = 构建脚本误改 CFBundleShortVersionString**；v1.4.105 修复并真机验证通过。

## 根因（硬证据，别再踩）
- v1.4.102 为修"覆盖安装不上"，在 `build-bh-simple.py` 把主 Info.plist 的 **`CFBundleShortVersionString` 从 TikTok 原始 `43.7.0` 改成了我们的版本号**（如 1.4.104）。
- TikTok 读 `CFBundleShortVersionString` 判断版本新旧 → 看到 `1.4.104`（远低于它预期的 43.x）→ 判定"旧版本需更新" → **每次启动弹升级提示**。
- 对照证据：`TikTok_43.7.0_BH.ipa` 是 `CFBundleVersion=437030 / ShortVersion=43.7.0`；v1.4.104 产物是 `437104 / 1.4.104`。v1.4.88-101 装机不弹提示 = ShortVersion 还是 43.7.0。
- **修复原则**：`CFBundleVersion` 必须递增（437105，iOS 靠它判覆盖升级），`CFBundleShortVersionString` **永远保持 TikTok 原始版本号不动**。浮窗自己的版本号走 `xnower-config.plist` 的 `XNOWER_BuildVersion`，与主 Info.plist 无关。
