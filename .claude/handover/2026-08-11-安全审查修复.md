## 🔑 关键技术经验（血泪新增）

1. **设备掉线=静默**：poll 是唯一生命线（无独立心跳），失败 `if(!r) return` 后 `_isConnected` 保持 YES，后端标记离线但设备无感永不恢复 → 任何网络失败都必须有"检测→重连"回路
2. **生产 SECRET_KEY 勿轮换**：crypto.py 用 `sha256(SECRET_KEY)` 派生 Fernet，存量 `enc:v1:` 账号凭证解不开。生产已用强随机 `bcc4a372...`，只堵"默认值"路径
3. **生产所有设备已绑 UUID secret** → 可安全关闭迁移期放行，不锁设备
4. **本地 Python 环境损坏**（cryptography/pip 报 `cannot import name`）：改逻辑验证用独立复刻，不依赖本地 venv；部署语法检查用 VPS venv
5. **deploy 用 plink + pscp**（G:/Temp/），密码在 .env.local，hostkey 指纹硬编码在 deploy-vps.ps1
6. **VPS 代码目录**：/opt/xnow-flow-git（git pull）+ 复制到 /opt/xnow-flow（运行），restart xnow-backend
7. **VPS 是 Python 3.8**：仓库代码不能用 `dict | None`/内置泛型注解（3.10+），用 `Optional[...]` 兼容。且历史部署只复制部分文件，main.py import 的模型/路由可能在 VPS 缺失 → 部署后必须 `systemctl` 检查启动，不能只看 cp 成功
