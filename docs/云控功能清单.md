## 开发路线图建议（三批）
1. **第一批·练准手（假成功治理）**：修 search_keyword / follow_user（导航重写）/ like·follow 用 Safe 版 / void 命令默认兜底 L643 / comment·share 假成功。**目标：所有命令真实生效，不空返 success**
2. **第二批·补指挥部（pptx 后台功能）**：按「缺口表」优先做：视频采集入库 → 素材库（昵称/签名/头像/图片）→ 批量取消关注 → 指定视频评论 → 自动回复 → 批量养号参数 → 设备实时监控
3. **第三批·填手机端**：直播粉丝采集（真采点赞用户）、实时翻译、快捷指令自动化养号、一键采集粉丝落地到 XNOW 面板
