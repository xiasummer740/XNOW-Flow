## 三、执行步骤（每步有验收线）

### Step 0 · 网络层验证（当前）
- 装 **v1.4.137**（installHooks 根因修复：网络拦截层从未启动）→ 下发 `net_diag` 复测
- 判定：`session.hits > 0` → TikTok 走系统栈 → **路线 C**（NSURLSession 复用 headers，最轻）
- `= 0` → 路线 B（借力 TikTok 网络类）/ 路线 A（逆向 X-SS-STUB 签名）
- 验收：网络路径一锤定音，路线选定

### Step 1 · 网络层四件套（全部 PPTX 功能的地基）
- 打通 like / follow / comment / edit 网络层真执行
- 验收：网站下发四指令 → 手机真成功 → 结果读回

### Step 2 · 评论区采集链路（引流第一环）
- 设备端网络层采集指定视频评论用户 → 上报 `collected-data` 入库
- 网站补：采集任务创建 + 数据筛选/分组/去重界面（后端接口大部分已有）
- 验收：网站建采集任务 → 手机真采 N 评论用户 → 入库可见可筛选

### Step 3 · 关注 + 点赞任务（引流第二环）
- 设备端网络层 follow / digg 批量
- 后端 `task_engine` 接 collected-data 分组 → 关注/点赞任务
- 网站：建任务（选分组/数量/间隔/设备组）+ 进度 + 明细导出
- 验收：网站"关注 XX 分组 100 人" → 真成功 100 → 明细可导出

### Step 4 · 补齐引流闭环
- 粉丝采集、直播间采集（同类接口扩展）；网站界面完善
- 验收：三采集全通 + 关注/点赞全链

### Step 5 · 一拖多设备组
- 设备组批量任务下发（device-groups 接口已有）
- 验收：选 5 台手机 → 批量任务 → 每台明细可看

### Step 6 · PPTX 其余功能逐个填
- 发视频 / 私信/回关私信 / 翻译 / 快捷指令 / 批量注册滑块 / 批量养号
- 每功能一个验收线
